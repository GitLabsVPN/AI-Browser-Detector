# AI Content Detector

A **browser extension** that analyzes webpage content to estimate the **likelihood of AI generation** using a lightweight Python API and JavaScript frontend.

## 🚀 Features
- Detects if text on a webpage was generated by an AI
- Uses simple heuristic rules with potential for expansion
- Injects a floating UI alert with **AI detection score** and **assessment**
- Easy to deploy and use

## 🧰 Technologies Used
- Python (Flask) for backend API
- JavaScript for content injection
- Manifest.json for Chrome/Firefox extension configuration
